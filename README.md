# a11y-shiken demo site — つばめ台コミュニティセンター（架空）

アクセシビリティ検査スキル [a11y-shiken](https://github.com/taichiyam/a11y-shiken) の検証用ダミーサイトです。架空施設「つばめ台コミュニティセンター」の静的サイトを、2つのバージョンで公開しています。

- **ok/** — WCAG 2.2 Level A + AA 適合を目指した実装
- **ng/** — 同一レイアウトのまま、アクセシビリティ上の問題を**意図的に**仕込んだ実装

## 用途

a11y-shiken の動作デモ・精度検証・ハンズオンの検査対象として使います。ng 版の問題は教材として意図的に仕込んだものです。**修正しないでください。**

## サイト実体の管理について

このリポジトリは配信専用です。サイト実体の正は本体リポジトリ a11y-shiken の `examples/site/` にあり、変更はすべて本体側で行ってからここへ反映します（このリポジトリへの直接の変更は行いません）。

仕込んだ問題の一覧（ground truth）は本体リポジトリ側でのみ管理しています。
